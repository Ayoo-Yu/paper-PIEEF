# Reproducing reported items

Run `python scripts/reproduce.py --all --from-results` from the repository root.
The entry point exports frozen table cells and source-based quantitative views without training.
Paper snapshots remain in `figures/paper/`; portable redraw layouts may differ.
Editable schematic SVGs are copied as source exports; original EMF snapshots are retained.
The original Table 7 raw per-run timing logs were not retained.
