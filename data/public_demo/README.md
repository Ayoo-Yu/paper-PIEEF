# Public Demo Data

This folder stores synthetic demonstration data for public reproducibility.

Generate files with:

```bash
python /Users/yuzhongze/Desktop/PI-EEF/scripts/generate_public_demo_data.py \
  --output-dir /Users/yuzhongze/Desktop/PI-EEF/data/public_demo \
  --turbines 29 \
  --days 60 \
  --seed 2026
```

Expected outputs:

- `DMS.csv`
- `turbines.csv`
